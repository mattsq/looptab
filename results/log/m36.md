# M36 — depth extrapolation re-tested on the cross-cell MIXER (Task B, `iterated`): the first transferable step operator in the repo — but ONLY with step-aligned supervision

**WHY.** Every depth-extrapolation null (M1/M3a/M3b/M7/M8, §11.2 #4) was measured on the flat `trm`,
which §4 now calls feedforward-equivalent. M24 put `trm_mixer` on `iterated` but only in-distribution
(loop depth coupled to T, no over-unroll). A 2026 preprint, "When Does Recurrence Become an
Algorithm? Convergence Selection in Weight-Tied Looped Transformers" (arXiv 2607.20594), reports
that weight tying selects a serial step-wise solution, that extra test-time loops recover longer
computations, that a depth-matched untied model extrapolates worst, and that an "operator-first"
curriculum removes a learning barrier. M36 asks the §3 extrapolation question of the mixer.

**Setup (both runs).** Rule 110, w=24, distractors=0, n_train=4000, n_test=1000, 100 epochs, 8 seeds,
CPU, `parallel_workers: 4`. Every matched arm within ±1.2% of the `trm_flat` reference budget
(16,176 params). Extrapolation test rows come from the held-out `test_sample_seed`, same task
function. Classification sign: positive Δ favours the first arm. Sign test is the two-sided exact
binomial (8/0 ⇒ p=.0078).

| majority baseline | 0.535 | | | 0.537 |

**Reading.**
- In-distribution the M24 result reproduces: Δ(trm_mixer − ff) = +0.238 acc, 8/0; Δ(trm_mixer − trm_flat) = +0.242, 8/0.
- **No extrapolation at all, for any arm.** At T=6 (two CA steps past training) every arm at every
  R' sits at the baseline band (0.50–0.556); EM = 0 everywhere at T ≥ 6.
- **Over-unrolling destroys the in-distribution answer.** `trm_mixer` at T=4 falls 0.903 → 0.539 at
  R'=6. The `trm_mixer_r8` arm peaks exactly at its trained R'=8 (0.735 → 0.840 → 0.936 → 0.708 at
  R'=4/6/8/12). Each arm learned a fixed-depth circuit, not a step.
- Deep supervision off vs on: no difference (Δ −0.011, 2/6, p=.29).
- **Tying HURTS in distribution here:** the budget-matched untied mixer beats the tied one,
  Δ(trm_mixer − untied_mixer_matched) = −0.082 acc / −0.636 EM, 0/8. (2607.20594's tied-wins claim
  concerns extrapolation, where both are at baseline, so this does not test it.)

## M36b — T-curriculum (T ~ U{1..8}) + STEP-ALIGNED deep supervision (loop step i ↔ s_i)

The M3b recipe carried to the mixer — the closest in-repo analogue of an operator-first curriculum.
Config `configs/experiments/m36b_mixer_stepds_curriculum.yaml`; record
`results/m36b_mixer_stepds_curriculum_20261024T023808*` (wall clock 13.3 min). T_test ∈ {12, 16} is OOD.

Diagonal R' = T (one loop per CA step):

| arm | T=4 acc / EM | T=8 acc / EM | **T=12 acc / EM (OOD)** | **T=16 acc / EM (OOD)** |
|---|---|---|---|---|
| `trm_mixer_stepds` | 0.998 / 0.965 | 0.992 / 0.939 | **0.983 / 0.886** | **0.966 / 0.823** |
| `trm_mixer_finalds` | 0.818 / 0.043 | 0.666 / 0.002 | 0.557 / 0 | 0.529 / 0 |
| `trm_flat_stepds` | 0.846 / 0.053 | 0.595 / 0 | 0.514 / 0 | 0.518 / 0 |
| `untied_mixer_matched` (depth 8, DS off) | 0.586 / 0 | 0.580 / 0 | 0.544 / 0 | 0.536 / 0 |
| `ff_matched` | 0.578 / 0 | 0.557 / 0 | 0.536 / 0 | 0.538 / 0 |
| majority baseline | 0.535 | 0.541 | 0.542 | 0.554 |

Δ(trm_mixer_stepds − every other arm) on the diagonal is +0.15 … +0.47 acc and **8/0 (p=.0078) in
all 16 (T, arm) cells**, including both OOD depths. Per-seed accuracy at T=16:
0.991, 0.995, 0.991, 0.918, 0.886, 0.966, 0.988, 0.995 (every seed far above the 0.554 baseline).

**Reading.**
- **This is the first transferable step operator in the repo.** Trained on T ≤ 8, the step-aligned
  mixer recovers s_12 and s_16 by running 12 and 16 loops: 0.983 / 0.966 per-cell accuracy, 0.886 /
  0.823 whole-row exact-match, where every control is at baseline. §3's "strongest evidence"
  diagnostic passes for this arm.
- **It needs BOTH ingredients — a conjunction, each one-knob-isolated:**
  - the mixing operator: the flat loop with identical supervision fails (0.846 at T=4, baseline beyond);
  - step-aligned supervision: the same mixer with final-state DS under the same curriculum fails
    (0.818 at T=4, baseline beyond); M36 shows single-depth final-target training fails too.
- **Off-diagonal collapse is expected, not a defect.** On a non-convergent CA, R' ≠ T computes
  s_{R'}, the wrong state, so accuracy at baseline off the diagonal is what a correct step operator
  must do. This is a transferable operator, not adaptive compute: the caller must supply T.
- The in-distribution T=8 point (0.992) also dissolves the M3a/M24 "deep CA is unlearnable one-shot
  at T ≥ 8" wall for the mixer — that wall was a supervision limit, not an architecture limit.
- EM decays slowly with depth (0.965 → 0.939 → 0.886 → 0.823) as per-step errors compound; seeds 3
  and 4 are the weaker ones at every depth.

## Caveats (do not overclaim)

1. **Privileged supervision.** Step-aligned DS gives the loop the intermediate states s_1 … s_T —
   strictly more information than a final-target model sees. The claim is "given the trajectory, the
   mixer learns a repeatable local step and iterating it extrapolates", NOT "the loop discovers the
   algorithm from input/output pairs" (M36 says it does not). The flat loop had the same information
   and failed, so the operator — not the information alone — is the active ingredient.
2. **The tying control is not clean under step supervision.** `untied_mixer_matched` ran with DS off
   (as M3b's untied arm did) and cannot be unrolled past depth 8 by construction. Whether an untied
   mixer given per-layer step-aligned readouts matches the tied one at T ≤ 8 is untested. The OOD
   result is still tying-specific in the trivial sense that only a tied loop can run 12 or 16 steps.
3. **Narrow scope:** one rule (110), one width (24), one curriculum range (1..8), OOD up to 2× T_max.
   Rule 110 is a 3-cell local rule, so a token mixer can represent it exactly; whether this holds for
   wider-neighbourhood or non-uniform rules (`mixed_converge`-style) is open.
4. The single-T run (M36) and the curriculum run (M36b) differ in two knobs (curriculum + alignment);
   the within-M36b `finalds` arm isolates alignment under the curriculum, and M36's arms show a single
   training depth also fails, but a single-depth step-aligned arm was not run.

## Other things checked in passing

- **The ACT router-initialization trap (arXiv 2604.21999) does not apply to M23.** looptab's halting
  head is trained by BCE to predict correctness, training always runs every segment
  (`train_act`, `src/looptab/train/loop.py:832–846`), and halting is used only at evaluation — so
  halting never sets training depth, which is the trap's precondition.

## What this changes

- §11.2 #4 ("no transferable step operator; no depth-extrapolation") is now FLAT-LOOP / final-target
  specific. On the mixer with step-aligned supervision it is overturned at T ≤ 2·T_max on rule 110.
- Open next: the clean untied-with-step-DS control; other rules and widths; how far past 2·T_max it
  holds; and whether a weaker signal than the full trajectory (e.g. a few intermediate states, or
  progressive loss on the mixer) is enough.
